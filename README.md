# NAILS BY LISA

Upload the **contents** of this folder to the root of your GitHub repository. The site is already built; no package installation is needed.

For GitHub Pages: open repository Settings → Pages → Source and choose **GitHub Actions**. Keep `.github/workflows/pages.yml` in the repository; it publishes on pushes to main or master. Your site files, including index.html, assets, and vendor, must stay together.

To preview locally, serve this folder with a static web server. Directly double-clicking index.html does not reliably load JavaScript modules.

Edit service prices and the real scheduling URL or email in `site-config.js`. Until connected, the planner prepares a copyable/downloadable appointment request and does not send or reserve anything.

The customer try-on includes photographic hand images in three skin tones, 64 shades plus custom colors, shape/length choices, art styles, finishes, and accent nails. Portfolio and try-on images are generated concepts, and service prices are illustrative. Screen colors and effects are digital guides. A separate rotatable 3D shape study is also included. Third-party licenses are in vendor/ and assets/fonts/.
